# Employee Management System

## [Video Demo](https://drive.google.com/file/d/1ejYylBJh9h6nW0q3SYZEt5heNANcgihp/view?usp=sharing)

## Description

A full-stack employee management system built with **Spring Boot** (Java), **React**, **PostgreSQL**, and **AWS S3** for profile image storage.

## Tech Stack
* **Frontend:** React, Axios, React Router, Toast Notifications
* **Backend:** Spring Boot, PostgreSQL, Spring Data JPA, AWS SDK (S3)

## Features
* Add new employee profiles with details such as name, email, address, phone number, job title, profile picture, and account status (active/inactive).
* Edit existing employee profiles, including the option to update only specific fields.
* Upload and display profile images via AWS S3.
* Delete employee profiles from the system.
* Responsive UI built with React, ensuring a smooth user experience across devices.
